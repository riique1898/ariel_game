# Desafio da Sobrevivência

Jogo em HTML, CSS e JavaScript para o projeto prático de Desenvolvimento de Jogos.

## Objetivo

Sobreviva o maior tempo possível, desviando dos inimigos e coletando estrelas para alcançar a maior pontuação.

## Controles

- **WASD ou setas:** movimentação.
- **Espaço:** dash, um avanço rápido com recarga de 1 segundo.
- **P:** pausa e continua a partida.

## Regras

O jogador começa com três vidas. Ao tocar em um inimigo, perde uma vida e recebe um intervalo de proteção. A partida termina quando as vidas acabam. O temporizador aumenta a dificuldade: inimigos surgem mais rapidamente e ficam mais velozes a cada nível. O recorde é salvo no armazenamento local do navegador.

## Funcionalidades extras

1. Poderes temporários: escudo e tempo lento.
2. Dois tipos de inimigos: orbes oscilantes e caçadores diretos.
3. Dash acionado pela barra de espaço.
4. Sistema de combo para coletas consecutivas.
5. Conquistas aos 100 pontos e um minuto.

Abra index.html em um navegador para jogar.
